# Vibe Delivery — Frontend (Vite + React)

This workspace contains a frontend scaffold for the Vibe Delivery Service.

Quick start:

1. Open a terminal and change to the frontend folder:

```bash
cd "frontend"
```

2. Install dependencies:

```bash
npm install
```

3. Start the dev server:

```bash
npm run dev
```

The app will open at `http://localhost:3000` (Vite default). The home page shows "Hello delivery parcel".

Notes:
- Frontend uses React + React Router, Tailwind CSS and daisyUI, and `framer-motion` for simple animation.
- Backend (Node + Express + MongoDB) will be added later under a separate folder.
